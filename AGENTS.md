# Regras
- Sempre siga as filosofias de desenolvimento:
  - Clean Code
  - Keep It Simple, Studip
  - You Ain't Gonna Need it
- Leve em consideração que algum dia no futuro, um humano mexerá neste repositório, logo, tudo precisa estar claro; com claro, eu digo, sem comentários desnecessários por todo o código, o código deverá ser desenvolvido para que seja claro ao ponto de ler e já entendê-lo.
- Enquanto houver dúvidas ou incertezas, PERGUNTE, não é para desenvolver NADA sem que todos os pontos estejam esclarecidos.
